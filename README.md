# Research_Paper_Summarizer
# Built With

LangChain – Agent orchestration and LLM workflow management
Streamlit – Interactive web application frontend
Open-source LLM – Research paper analysis and summary generation

The application uses LangChain to coordinate the summarization pipeline and Streamlit to provide a user-friendly interface for generating structured research paper summaries.
